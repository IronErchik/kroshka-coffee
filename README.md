# Сайт кофейни «Крошка»

Это учебный сайт кофейни. Он написан на HTML, CSS и JavaScript. На сайте можно выбрать кофе и попробовать оформить заказ. Его можно открыть на компьютере и телефоне.

## Как открыть сайт

Откройте файл [index.html](./index.html) в браузере. Для этого не нужно ничего устанавливать. Интернет тоже не нужен.

Ещё сайт можно запустить через Node.js, если он установлен. Откройте терминал в папке проекта и введите:

```powershell
npm start
```

После этого откройте в браузере http://127.0.0.1:4173.

## Что можно делать на сайте

- Посмотреть шесть напитков.
- Найти напиток по названию или выбрать категорию.
- Добавить напиток в избранное.
- Выбрать объём чашки и молоко. Цена изменится в зависимости от выбора.
- Добавить напитки в корзину, поменять их количество или удалить.
- Заполнить форму заказа и увидеть чек.

Корзина и избранное сохраняются в браузере, поэтому после обновления страницы они не пропадают.

## Про заказы

Это учебный проект, поэтому заказ никуда не отправляется и оплачивать его не нужно. Кофейня и её часы работы вымышлены.

Имя, телефон и комментарий из формы никуда не отправляются и не сохраняются после обновления страницы. Чтобы принимать настоящие заказы, сайт нужно доработать.

## Что находится в папке проекта

- [index.html](./index.html) — текст, кнопки, карточки напитков и другие элементы страницы.
- [styles.css](./styles.css) — цвета, размеры, отступы и расположение элементов.
- [app.js](./app.js) — поиск, избранное, выбор напитка, корзина и форма заказа.
- [server.js](./server.js) — позволяет открыть сайт через команду npm start.
- [package.json](./package.json) — команды для запуска и проверки кода.
- [assets/](./assets/) — картинки напитков и значок сайта. Картинки созданы с помощью ImageGen, а значок и иконки сделаны в SVG.
- [image-prompts.json](./image-prompts.json) — описания, по которым создавались картинки.
- [preview-desktop.png](./preview-desktop.png), [preview-menu.png](./preview-menu.png) и [preview-mobile.png](./preview-mobile.png) — скриншоты сайта.

## Как проверить JavaScript

Если установлен Node.js, введите в терминале:

```powershell
npm run check
```

Эта команда проверяет синтаксис JavaScript. Работу кнопок и внешний вид можно проверить, открыв сайт в браузере.
