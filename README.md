# Крошка — кофе и маленькие радости

Адаптивный сайт кофейни по визуальному референсу: тёплый кремовый фон, белые округлые карточки, медные акценты и выразительная антиква. Все семь фотографий сгенерированы специально для проекта встроенным ImageGen. Иконки и знак кофейни нарисованы в SVG.

## Открыть сайт

Можно открыть `index.html` в браузере напрямую. Установка пакетов и подключение к интернету не нужны.

Для локального сервера из этой папки:

```powershell
npm start
```

Адрес: http://127.0.0.1:4173. Другой порт: `$env:PORT = 4200; npm start`.

## Что работает

- Меню из шести напитков; категории, поиск и избранное.
- Карточка напитка с выбором объёма и молока, пересчёт цены.
- Корзина с изменением количества, удалением позиций и итоговой стоимостью.
- Корзина и избранное сохраняются после обновления страницы.
- Демо-оформление: имя, телефон, время самовывоза, комментарий и чек заказа.
- Мобильная версия, управление с клавиатуры, системное уменьшение анимаций.

## Границы демонстрации

Это самостоятельный frontend-концепт. Заказы не отправляются в настоящую кофейню, платежи не проводятся. Форма явно обозначена как демонстрационная. Контактные данные остаются только в оперативной памяти страницы и не отправляются по сети; в локальный чек не записываются. Название кофейни, её локация и часы работы вымышлены.

Для коммерческого запуска нужны реальные реквизиты и меню кофейни, серверный API приёма заказов, интеграция с кассой/уведомлениями и при необходимости оплата. Локальный `server.js` только раздаёт файлы сайта.

## Файлы

- `index.html` — разметка.
- `styles.css` — стили и адаптивная сетка.
- `app.js` — меню, конфигуратор, корзина, оформление.
- `assets/` — семь сгенерированных фотографий и SVG-иконка вкладки.
- `image-prompts.json` — полный набор промптов ImageGen.
- `preview-desktop.png`, `preview-mobile.png` — снимки готового сайта, если сохранены при проверке.

Проверка синтаксиса: `npm run check`. Внешних библиотек, аналитики, внешних шрифтов и запросов к фотобанкам нет.
